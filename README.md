# Sage Advice

A line of wisdom a day, a short worth watching, and a place to be still.

Free, no account, everything you keep stays on your device. Live at https://sv-sa.netlify.app.

## Develop

```bash
npm install
npm run dev
```

`npm run build` type-checks and builds to `dist/`. `npm run check:videos` confirms every short in the library still plays on YouTube (add `--write` to stamp creator and verification date).

## Deploy

Pushes to `main` build and deploy on Netlify (settings in `netlify.toml`).
